# Canvas handwriting font

`Yomogi-Regular.woff2` is the unmodified webfont from
[Yomogi v3.00](https://github.com/satsuyako/YomogiFont/tree/ver3.00).
Its SIL Open Font License is in `../../public/fonts/Yomogi-OFL.txt` and is
copied into the component build for redistribution.

The draw style uses Shantell Sans first and Yomogi for Japanese glyphs.
Vite bundles the font locally; no external font request is needed for Yomogi.
